- `all_transits.png`: every predicted transit at P = 18.05665 d (`plot257.py`).
- `fold.png`, `odd_even.png`, `phase05.png`: sector-97 fold, odd/even transits, phase 0.5.
- `s108.png`: sector 108 full-frame images (TESScut), both predicted transits; the model is the s3/30/97 fit, not refit.
- `fold_4p35.png`: the second signal Dagfinn found, P = 4.35331 d, all four sectors with the 18-d transits masked.
- `fit257.py`: batman fit (free, b profile, density fixed) and per-transit depth scale. Needs `lightkurve`, `batman-package`, `scipy`.
