# TESS candidates

Plots and check scripts for transit candidates found in TESS light curves and discussed on [Planet Hunters TESS Talk](https://www.zooniverse.org/projects/nora-dot-eisner/planet-hunters-tess/talk).

One folder per TIC. Each holds the plots linked from its Talk thread and the scripts that made them. The scripts download public data from MAST with lightkurve and run on their own.
